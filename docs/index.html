03 FEATURES

Engineered for every frame

AZYRON CLIENT is not a texture pack and it is not a settings preset. It is a curated Fabric stack — wired together, tuned and shipped as one download.

Rendering rewritten

Sodium replaces the vanilla render path with a modern, batching pipeline. Chunk meshing moves off the main thread, draw calls collapse, and the GPU stops waiting on the CPU. This is where most of the FPS comes from.

  • Sodium
  • Async chunk build
  • Reduced draw calls

Silent simulation

Lithium rewrites entity, block and chunk ticking so worlds full of farms and mobs stop being a slide show.

  • Lithium
  • Tick optimization

Memory discipline

FerriteCore eliminates duplicate model and state data, cutting heap pressure and smoothing garbage-collection spikes.

  • FerriteCore
  • Lower heap

Nothing wasted

EntityCulling and MoreCulling skip geometry the camera can never see — through walls, behind blocks, outside the frustum.

  • EntityCulling
  • MoreCulling

Adaptive frame pacing

Dynamic FPS relaxes the render loop whenever Minecraft is out of focus, so alt-tabbing no longer cooks your machine.

  • Dynamic FPS
  • Cooler hardware

05 ABOUT

Built for players who
notice the stutter.

AZYRON CLIENT started with a simple frustration: great hardware still felt slow because of how Minecraft schedules its frame. So instead of shipping another settings guide, we assembled the strongest, most stable performance stack available for Fabric — then tuned it as one product.

The result is deliberately narrow. One Minecraft version, one loader, one release channel. Nothing experimental, nothing that fights another mod, and no telemetry. Just the fastest path we know to a smooth session.

06 SUPPORT

Need a hand? Read this first.

The answers that cover almost every question we get. Still stuck? The issue tracker is open.

Does AZYRON CLIENT work with other mods?

Yes. It ships only client-side performance mods that are known to coexist with gameplay, shader and utility mods. Shader packs (Iris/OptiFine-style) are outside the pack's scope — install them on top at your own risk.

Which Minecraft versions are supported?

Release 1.0.0 targets Minecraft 1.21.11 on the Fabric loader, Java 21 or newer. Always match the exact version — Fabric will refuse to load a mismatched build, which is intentional.

JAR or MRPACK — which should I download?

Take the .mrpack if your launcher supports Modrinth packs: it installs the entire tuned stack for you. Take the .jar if you already run a Fabric instance and only want the AZYRON client core.

How are the download numbers counted?

The headline figure is Downloads Since Launch: it starts at 0 and counts only the downloads that happened after the counter went live. It is computed from GitHub's own release counters, minus a snapshot taken at launch — so every increment is a real download of a real file, tracked separately for the .jar and the .mrpack. The per-file "all-time" figure next to it is GitHub's lifetime total for that file. When GitHub cannot be reached we show the last confirmed value and label it clearly — we never invent a number.

The download didn't start. What now?

The button sends your browser straight to the file on GitHub's release storage and saves it immediately. If nothing happens, use the direct link button next to it — it is the identical official asset URL. Corporate networks, privacy extensions and aggressive ad-blockers are the usual culprits.

Is my data collected?

No accounts, no cookies, no trackers, no telemetry in the client. The server logs an anonymous download event (file name and timestamp) so the public counters stay honest.
